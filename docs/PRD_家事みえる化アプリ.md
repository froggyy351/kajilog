# **PRD: カジログ \-家事の負担をみえる化して平和な家庭を-** 

---

**一言でいうと**: 同棲している2人それぞれの家事実績が記録できて、スマホをタッチするワンアクションで記録できるアプリ。

# **Overview / Problem Statement**

IT企業に勤める27歳の佐藤健太は半年前に結婚し、妻と同棲を始めた。

妻は同じ会社に勤める同期で、夫婦共働きをしている。家事は50:50にするというのが結婚時からの基本方針だった。特に役割分担などは設けておらず、気付いた方が家事をするという運用だ。

しかし、ある日妻が健太にこう言った。

「私ばかり家事をしていない？　」

ただ、健太の思いは違った。掃除機もかけているし、トイレ掃除もしている。見えないところでちゃんとやっているんだけどなと思った。

ここでは、どちらも嘘をついていない。**お互いがどれだけ家事をしているか正しく認識できておらず、お互いの考える各家事に対しての重さが異なり、認識齟齬が起こっている。**

家事分担・記録アプリは既にあるものの、既存ツールは家事をする度に実績を入力しなければならず、同棲を始める人たち（シェアハウス、新婚、カップル）は常にいるが、この手間を取り除いたプロダクトはない。

# **Goals / Non-Goals**

## **Goals**

- それぞれの家事への貢献度を一目で分かるようにする。  
- 完了した家事の履歴データを蓄積し、後から振り返れるようにする。  
- アプリの操作を挟まず、一回のタッチで家事実績を記録できるようにする。  
- 家事のモチベーションが湧くようにする。

## **Non-Goals**

* スマート家電やセンサー連携による全自動記録（やったふり、誤検知を懸念）  
* QRコード等、カメラ起動を伴う記録方式（手数がNFCより多いため不採用）

**Proposed Solution / Feature Description**

スマートフォンアプリ \+ NFCタグとして実装する。家事の実行場所（トイレ・洗面台・キッチン等）にタグを設置し、家事完了後にスマホをタッチするだけで実績が記録される。

*  **NFCタッチ記録:** タグにかざすだけで「いつ・誰が・何をしたか」を記録。アプリを開く・入力する手間が発生しない。「実績入力の手間」をゼロにする、本アプリの中心的価値。  
* **重み付けポイント制:** 家事ごとに所要時間・負担感で重みを設定し、単純な実施回数ではなく重み付きポイントで貢献度を算出。「掃除機はやってるのに」といった、重さの感じ方のズレを解消する。  
* **貢献度の統計:** 夫婦それぞれの累計・直近の貢献度推移をダッシュボードで表示。事実をそのまま見せることに徹し、責め立てないデザインとする。  
* **3D部屋間取りでみえる化:** お互いがどの家事に偏りがあるか、ビジュアライズすることで感覚的に把握できる  
* **家事履歴:** 完了履歴を時系列で蓄積し、週次・月次で振り返れる形にする。「あの時期はちゃんとやっていた」を後から示せる資産になる。

# **User Stories**

**US-001: やったことが、やったことになる**

* **ユーザーストーリー:** ユーザーの **佐藤健太** は、家事を終えたその場でタッチひとつで記録を済ませたい。それにより、後から入力を忘れて「実はやっていない」ことにされてしまう状況をなくせる。  
* **背景・課題:**  
  * 「荷物を持っている」「もう座ってしまった」「単純に忘れる」など、スマホを取り出してアプリを開くひと手間が、家事そのものより面倒に感じる瞬間がある。  
  * 従来の手動入力では、このわずかなストレスが原因で記録のつけ忘れが頻発してしまう。  
  * タグにタッチするだけなら、手を拭いた流れでその場で完結する。

### **US-002: どっちが何をやったか、聞かなくても分かる**

* **ユーザーストーリー:** ユーザーの 佐藤健太 は、妻が今日何をやったかをいちいち確認しなくても自然に把握したい。それにより、同じ家事を重ねてやってしまったり、お互いやったと思って放置してしまう抜けを防げる。  
* **背景・課題:**  
  * 明確な役割分担を決めていない運用では、「誰が何をやって、何がまだやってない」の情報が共有されないと、気づいたら二人ともゴミ出しを忘れていた、逆に洗い物を別々にやって効率が悪くなった、ということが起きる。  
  * 毎回「これやった？」と逐一報告し合うのは長続きしないため、お互いの状況が自然と視界に入る状態が必要とされる。

### **US-003: 忙しい週の頑張りも、なかったことにされない**

* **ユーザーストーリー:** ユーザーの 佐藤健太は、仕事や予定が詰まって家事に手が回らない時期があっても、これまで積み上げてきた実績まで軽く見られたくない。それにより、一時的なペースの波があっても、お互い納得した状態を保てる。  
* **背景・課題:**  
  * 立て込んでいる時期はできる量が一時的に減るが、これまでの記録は消えていない。  
  * 過去の記録が見えない状態だと直近の印象だけで「最近やっていない」と判断されがちで、忙しさへの理解も得にくくなる。  
  * 積み重ねた履歴が見える形になっていれば、貢献度に波があっても感情的なすれ違いを防げる。

### **US-004: 5分の家事と30分の家事を、正しく区別する**

* **ユーザーストーリー:** ユーザーの 佐藤健太 は、手間のかかる家事とすぐ終わる家事を同列に扱われたくない。それにより、件数ではなく実際の負担で貢献度を捉えられるようにしたい。  
* **背景・課題:**  
  * 「トイレ掃除も洗濯物たたみも同じ1件」という数え方では、時間や体力を要する家事を引き受けている側が損をした感覚になる。  
  * この「数の比較」による不公平感は強いストレスに繋がる。負担に応じた重み付けがあれば、件数の多寡ではなく実質の貢献度で比較できる。

# **Open Questions / Risks**

* **競合が追随したら、入力方式の差分は消える**: NFC対応はCAJICOが1機能足せば実装できる。差分を入力方式だけに置かず、清算モデルを併せて差別化の柱にしているのはこのため。清算モデルは既存アプリのデータの持ち方そのものを変える必要があるため、追随されにくいと見ている  
* **セットアップの手間が、タグの枚数に比例しないか**: 1タグ＝1家事だと、15枚貼るなら15回の設定作業になる。アプリ側でどこまで簡略化できるか（App Clip、アプリ内でのタグ書き込み、Androidとの差）は要検証。ここでつまずくと、日々の手数は最小でも「初期設定が重い」プロダクトになってしまう  
* **タグの枚数と貼る場所**: 何枚まで現実的か（10枚か、20枚か、30枚を超えると破綻するか）。同じ場所に複数貼る場合（キッチンに料理・皿洗い・シンク掃除）、どれにタッチするか迷わない見た目にできるか。貼れない／貼りたくない場所（賃貸の壁、来客時の見た目）をどう扱うか
